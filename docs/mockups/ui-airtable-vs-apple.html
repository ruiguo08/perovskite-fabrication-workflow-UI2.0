风格对比 — Airtable vs Apple

同一组界面（实验列表 + 运行单清单）的两种处理。Airtable 代表“数据网格”一极：全出血密网格、类型化彩 色药丸、视图工具栏、勾选后浮出操作条；Apple（第 0 期已落地）代表“流程工作台”一极：留白与字重做层级、 圆点状态、安静填充。切标签对比，Airtable 的勾选行试试——浮出操作条是它的签名交互。
